Fotos de prueba

Tus fotos se procesan en este dispositivo; no se suben a ningún servidor.

Cómo se usa

  1. Abre una foto. Una SBS (dos vistas lado a lado) se ve en 3D. Una foto normal también funciona, pero se ve plana.
  2. Encuádrala. Pellizca para acercar, arrastra para mover y toca dos veces para centrar.
  3. Calibra con las gafas puestas. Toca el lado izquierdo para restar, el derecho para sumar y el centro para avanzar, hasta ver una sola cruz +.
  4. Ver en gafas. Dentro del visor: mantén pulsado para recalibrar y toca dos veces para salir.

¿Quieres 3D de verdad? Toma una foto, desliza el teléfono unos 6.5 cm a la derecha sin girarlo y toma otra. Únelas lado a lado: primera a la izquierda, segunda a la derecha.
